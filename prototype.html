3-1 결제 신규 화면 구매승인

상담원이 접수한 구매요청 건을 확인하고 구매승인 처리합니다. 승인되어야 배송대기로 넘어갑니다. 권한: 관리자 / 매니저 / 재무담당자.

베트남은 COD(대금상환)라 이 시점에 실제 결제가 일어나지 않으므로 구매요청 · 구매승인이라고 부릅니다. 이 화면(3-1 결제)이 구매승인 처리 페이지이며, 승인 전에는 3-4 배송 목록에 나타나지 않습니다.

3-4 배송 개선 요청 배송처리 · 계약서 출력

구매승인된 배송대기 건을 배송처리합니다. 배송처리 시 해당 고객의 계약서가 ZIP으로 일괄 다운로드되며, 행별 [계약서]로 개별 출력도 가능합니다. 권한: 물류 / 관리자 / 매니저.

① 행별 [계약서] = 그 고객 계약서 1건 개별 출력(PDF 인쇄). ② [선택 건 배송처리] = 선택한 고객의 계약서를 전체 ZIP 파일로 내려받고 고객상태를 배송중으로 전환. 이후 4-6에서 시리얼번호를 등록합니다.

4-6 시리얼번호 업로드 단말기 시리얼 등록

출고 단말기의 시리얼번호를 입력/업로드합니다. 업로드 양식은 주문키 · 시리얼 2열뿐입니다. 권한: 물류 / 관리자.

시리얼번호가 등록되면 1-2 고객관리의 해당 건 시리얼 + 상담창(OB CALL 관리)에 시리얼번호가 표시됩니다. 선납금 입금(3-9) + 시리얼 등록이 모두 완료되면 자동 구매완료(3-10) 처리됩니다. 등록된 시리얼은 기기 PW 발송과 3-6 해지대기의 기기반납 확인에 그대로 사용됩니다.

3-9 선납금 입금 신규 화면

선납금 입금 건을 입금액과 함께 확인 처리합니다. 권한: 재무담당자 / 관리자.

입금처리되면 1-2 고객관리의 해당 건 입금 로 갱신됩니다. 선납금 입금 + 시리얼 등록(4-6)이 모두 완료되면 자동 구매완료(3-10) 처리됩니다.

3-10 구매완료 처리 신규 화면

시리얼 + 입금이 모두 완료된 건을 구매완료로 확정합니다. 구매완료가 되어야 비로소 해지 접수가 가능합니다.

선납금 입금(3-9) + 시리얼 등록(4-6)이 모두 완료되면 자동 구매완료 처리됩니다. 아래 목록은 두 조건이 충족됐으나 아직 구매완료 전인 건으로, 임의(수동) 구매완료가 필요할 때 사용합니다. 구매완료가 되어야 1-2 고객관리에서 해지 접수(상담창) 진행이 가능합니다.

3-6 해지대기

해지 접수된 해지대기 건을 개별로 해지 승인해 종결합니다. 위약금을 실제 입금받은 금액으로 입력하거나, 반납된 단말기 시리얼번호를 입력하고 [해지]를 누릅니다. 권한: 관리자 / 매니저 / 재무담당자.

접수 단계에서는 위약금·기기반납을 선택하지 않습니다. 이 화면에서 둘 중 하나만 입력하면 그것이 곧 해지 방식이 됩니다 — 위약금 입금액 입력 → 해지(위약금), 시리얼번호 입력 → 해지(기기반납). 위약금 경로로 종결되면 컨텐츠 사용중단 대상으로 자동 등록됩니다(실제 차단은 시스템실에 요청). 미납으로 인한 학습 차단은 CMS 범위가 아니며 지금처럼 건별로 시스템실에 요청합니다.

1-34 패키지 구성 관리 개선 요청
