4-6 송장번호 업로드 📦 물건 발송

송장 미등록 건에 송장번호를 입력/업로드합니다. 권한: 물류 / 관리자.

송장번호가 등록되면 1-2 고객관리의 해당 건 📦송장 ✅ + 상담창(OB CALL 관리)에 송장번호가 표시됩니다. 선납금 입금(3-9) + 송장 등록이 모두 완료되면 자동 구매완료(3-10) 처리됩니다.

3-9 선납금 입금 신규 화면

선납금 입금 건을 입금액과 함께 확인 처리합니다. 권한: 재무담당자 / 관리자.

입금처리되면 1-2 고객관리의 해당 건 💰입금 ✅로 갱신됩니다. 선납금 입금 + 송장 등록(4-6)이 모두 완료되면 자동 구매완료(3-10) 처리됩니다.

3-10 구매완료 처리 신규 화면

송장 + 입금이 모두 완료된 건을 구매완료로 확정합니다. 구매완료가 되어야 비로소 중도해지(반품)가 가능합니다.

선납금 입금(3-9) + 송장 등록(4-6)이 모두 완료되면 자동 구매완료 처리됩니다. 아래 목록은 두 조건이 충족됐으나 아직 구매완료 전인 건으로, 임의(수동) 구매완료가 필요할 때 사용합니다. 구매완료가 되어야 1-2 고객관리에서 중도해지(상담창) 진행이 가능합니다.

4-3 수동입고처리

기기반납 건의 입고를 확인합니다. (4-1 입고 / 5-2-1 입고업로드 리스트 / 4-3 수동입고처리에서 동일하게 반영) 권한: 물류 / 관리자.

입고대기 상태(기기반납 경로)인 건만 표시됩니다. 입고 처리하면 고객상태가 반품입고로 바뀌고, 이후 3-6 환불에서 환불 처리합니다.

3-6 환불

취소·기기반납·위약금 경로의 환불을 최종 처리합니다. 환불요청 → 환불승인(최종) 2단계. 권한: 환불요청=상담원/관리자, 환불승인=관리자/매니저.

환불 파이프라인(취소접수 · 반품입고 · 위약금입금 · 환불요청)에 있는 건이 표시됩니다. 환불승인 시 종결 상태(취소 / 중도해지(기기반납) / 중도해지(위약금))로 마감되고, 위약금 경로는 ★컨텐츠 자동 사용중단됩니다.
