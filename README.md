# 베트남 WM-CMS — 개발요청 화면설명서 & 프로토타입

세일즈마케팅실 → 개발팀 전달용. 빌드 불필요, 브라우저에서 바로 열림.

- **`index.html`** — 개발요청 화면설명서. 신규/개선 개발요청 항목은 **빨강 박스 + [개발요청]** 라벨로 표시(참고/기존 설명과 구분).
- **`prototype.html`** — 클릭형 인터랙션 프로토타입. 개발요청 화면은 **빨강 박스 + 상단 배너**로 표시.
